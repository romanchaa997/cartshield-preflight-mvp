# Security policy

## Project scope

CartShield Preflight is a local static-configuration review demo. It does not probe live stores, perform penetration testing, or provide a security certification. Please do not use it to test systems without their owner's explicit authorization.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities publicly before coordinating with the maintainers. When this repository is created, the owner should enable GitHub Private Vulnerability Reporting if reports are to be accepted through GitHub. Until a private reporting channel is confirmed, use the repository owner's publicly listed contact method and do not include credentials, customer data, payment data, or other sensitive information in a report.

## Supported versions

Only the current default-branch version is intended for review; no release or long-term support policy has been established yet. The project is an MVP and should not be treated as production security tooling.
